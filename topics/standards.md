# 选题标准

## 全部满足才进「待写」

1. **真做得出来**：能在这台电脑或手机上真跑一遍，或者有用户的真实记录。做不出来的不写。
2. **有增量**：至少 2 条别处搜不到的东西（实测数字、踩坑、对比、一手判断）。
3. **说得出转发理由**：帮朋友省事 / 表达立场 / 收藏备用，至少占一个。
4. **不拼速度**：资讯类只写「慢半拍但真用过」的角度，不做当日快讯。
5. **承诺不超过证据**：标题的承诺不能超过发稿当天已有的证据。写明读者复现门槛（工具、花费、时间），至少给一个零门槛做法。（来源：2026-11-08 选题评审）
6. **号主是主角**：讲号主怎么指挥 AI、在哪里拍板，不把 AI 写成主角。
