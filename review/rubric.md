# 评审标准 v1

评审由 Opus 子任务执行。评审不知道作者是谁，只拿到稿件和对照材料。每项 1–5 分，并给出**具体到句子的**修改意见。

目标是超过对标号，不是对齐。对标只是七项之一。

## 1. 读者拿走什么（权重最高）
- 读完能做成什么？能用一句话说出来吗？
- 教程类：评审**按步骤真跑一遍**（或逐步核对命令、版本、前置条件）。跑不通 = 本项 1 分，整篇不过。
- 观点类：结论有没有可检验的依据？

## 2. 信息增量
- 列出本文中「别处搜不到」的内容（实测数字、踩坑、对比结果、一手判断）。
- 少于 2 条：不过。

## 3. 人味
- 有没有具体细节（时间、数字、报错原文、截图）、明确判断、承认失误？
- 逐句标出 AI 腔，对照 `review/ai-tone-checklist.md`。
- 有没有编造感（细节太顺、情绪太满、经历无法核实）？有就标红。
- 引文归属：每条引用分清是作者本人、作者转述的团队、官方文档还是其他作者；英文原话逐字核对。（2026-11-08 升级）
- 有没有替号主编动机或感受（「我一直想」「我是信的」）？号主没说过的一律标红。

## 4. 传播
- 读者会因为什么转发？（帮朋友省事 / 表达立场 / 收藏备用）说不出 = 低分。
- 标题：不看正文，能判断读完得到什么吗？有没有标题党？
- 开头三行：能不能让人读下去？

## 5. 挑刺读者
分别以两种身份读一遍，各列 3 条：
- 懂行的老手：哪里是水分、哪里说错了、哪里太浅。
- 刚入门的新手：哪里看不懂、哪一步卡住。

## 6. 盲测对比
- 同题材下，选一篇对标号的最好文章，和本文匿名放在一起，问：哪篇更值得转发？为什么？
- 本文输了：具体输在哪，怎么赢回来。

## 7. 更高的尺子
- 对照中英文最好的实践类写作（如 Simon Willison 的实测博客、Paul Graham 的 Write Simply）：本文离那个水平还差什么？

## 结论
- 总分与是否通过（第 1 项 < 4 或任何一项 ≤ 2 即不过）
- 最重要的 3 条修改，按收益排序
- 预测：阅读、分享相对本号均值是高 / 持平 / 低，并说明理由（发布后用真实数据核对）
