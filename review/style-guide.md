# 借风AI 写作风格指南

定位：一个普通人亲手跑过的 AI 实验。读者看完应该觉得：这个人真的做了，写得具体，说话不绕，有自己的判断。

对标分工：教程的实操感学卡兹克，人味学橘AI，观点密度学李继刚。本指南主要提炼自卡兹克写作方法，并按借风的定位做了取舍。

来源标记：[K]=khazix-writer，[H]=humanizer，[S]=shuorenhua，[借]=借风自己的要求。

---

## 0. 先定三条底线 [借][K]

1. 没做过的不写成做过。没有真实经历，就写「我还没试，但想试」。
2. 一篇文章只回答一个问题，并且这个问题是作者真的好奇或真的被卡住过。
3. 动笔前过一遍 HKR：有趣吗（H）、有信息量吗（K）、戳到情绪吗（R）。至少占两项。只占一项就重新想角度。

来源：[K] 选题质检（HKR）。

---

## 1. 开头：前三行 [K][借]

目标：三行内让读者知道「谁、在做什么事、结果有点意外或有点麻烦」。

做法：
- 第一行落在一件具体的、近期的、可以想象的事上。可以是一个场景、一个意外结果、一个报错。
- 第二行交代你为什么要做，或者你预想的是什么。
- 第三行抛出悬念或结果的一角，让人想往下读。

常用的几种起手（卡兹克的归纳，借风可用）：
- 叙事启动：「事情是这样的。」后面直接接经过。
- 荒诞事实：先抛一个让人愣一下的结果。
- 热点破题：最近大家都在聊的某个工具，我去试了。
- 好奇心驱动：刷到什么，觉得有意思，就动手了。

不要：
- 宏大背景（「AI 时代已经到来」）。
- 复述标题。
- 预告结构（「本文分为三部分」）。

自检：删掉第一段，读者会不会损失信息？如果不会，第一段就是废的。

来源：[K] 开头必杀技；[H] 预告式铺垫、背景开头。

## 2. 实测文章的结构 [K][借]

卡兹克把调查实验和产品体验写成一条「英雄之旅」线：遇到好奇或困境，动手做，踩坑，拿到结果。借风的实测文沿用，但加上教程该有的可复现信息。

骨架：

1. 起点。我想知道什么 / 想解决什么，用一个具体困境，不要抽象命题。
2. 先说结论的一角，或者说清楚预期。读者要知道值不值得往下读。
3. 环境与成本一句话交代：工具及版本、花了多少钱、用了多久。
4. 过程。按真实顺序写，每一步带一个真实反应（卡在哪、改了什么、结果如何）。
5. 翻车。至少写一次失败或意外，附报错原文或截图。
6. 结果。展示最终产出，并说清楚「这到底好不好」。
7. 判断。值不值得用，适合谁，不适合谁，我自己会不会继续用。
8. 收尾。轻量，见第 6 节。

多个工具或多个案例对比时，逐一展示，不要一次性罗列。每个带一句真实点评。排列顺序按情绪曲线，由浅到深，最出乎意料的放在最后。这是卡兹克从喜剧「升番」里借来的节奏法：每一轮都比上一轮更进一步。

教程步骤需要读者照做时，可以用编号和小标题。卡兹克的叙事长文几乎不加小标题，靠转场句衔接，但他的写法针对「读故事」；借风有大量「照着做」的内容，需要读者能找回自己卡住的那一步。取舍：叙述段不加小标题，操作段加。

每一节都问自己：读完这一节，读者手里是否有一个能今天就做的动作，或者一个新判断？没有就合并或删。

方法类文章（「我的 N 条经验」）要老实说学习成本、时间曲线和常见失败点，不只画饼。

来源：[K] 五种文章原型、英雄之旅、逐一展示与升番、方法论结构原则。

## 3. 怎样展示真实证据 [借][K]

证据是借风与泛泛的「AI 测评」最大的区别。每个关键结论至少配一个读者可以对照的痕迹。

按重要性排序：

1. 报错原文。贴原文或截图，不要转述成「报了个错」。
2. 截图 / 录屏。关键一步的前后对比，标注在哪里发生了变化。截图中的时间、版本号别裁掉。
3. 时间与花费。写真实的零碎数字：「折腾了 2 小时 40 分钟，花了 18.6 元 API 费用」，比「很快」「很便宜」强得多。
4. 版本与环境。工具名加版本、模型名、系统。
5. 失败次数。「试了 7 次，第 5 次成功」。
6. 关键提示词和命令。放原文，方便复制。
7. 对比对象。和哪个工具比，条件是否一致。

规则：
- 没有证据的结论，降级成「我感觉」，或者去补证据。
- 不用「大幅提升」「效率翻倍」。要么给两个数，要么不说。
- 数字不凑整。不确定的写「大概」，别装精确。
- 不能核实的第三方事实（价格、功能），查一下再写，或注明「写作时我看到的是」。

来源：[K] 亲自下场、不编假设性场景；[H] 圆数字、borrowed authority；[S] 不编出处。

## 4. 借风的声音 [借][K]

一句话：有见识的普通人，认真聊一件自己亲手做过的事。

规则：
- 平实。能用「用了」就不用「使用了」；能说「卡住了」就不说「遇到了瓶颈」。
- 具体。工具有名字，数字有来源，场景有时间地点。
- 敢认失败。写「我配了三次都没成」，比写「过程略有波折」可信。承认不会、不确定，也是信息。
- 有判断。每篇都要有一个明确的「我觉得值/不值」，并给出原因。不做两边讨好的总结。
- 体感代替形容词。「我愣了一下」比「我非常震惊」好；没有真实体感就不写。
- 不居高临下。不写「你应该」；写「我是这样做的，你可以这样试」。
- 先站在读者处境里再提观点。卡兹克的做法是先把对方的处境说具体，承认合理，再说自己怎么看。
- 偶尔直接对读者说话（「你也可以试试」），用在需要读者行动的地方，不要通篇都是。
- 口语是副产品：「说实话」「怎么说呢」这类词自然出现就行，不要凑配额。
- 本号约定的标点：尽量少用冒号、破折号、双引号，强调或引用用「」。

节奏：
- 长短句交替，偶尔一句话成段，用来停顿，不用来复述。
- 离题一小步之后，用一句话把话题拉回主线（扣主线句）。别一下跑远再硬拽回来。
- 前面埋的东西后面要回应。开头的那个报错、那个预期，结尾应该回头看一眼，视角已经变了。这就是卡兹克说的「契诃夫之枪」。

升维（可选）：卡兹克几乎每篇都从具体事件连到更大的参照。借风不强制。能自然想到就写一两句，想不到就别写，硬升华是 AI 腔里最明显的一类。

来源：[K] 核心价值观、节奏、谦逊铺垫、对立面理解、契诃夫之枪；[H] voice 保留不确定与具体细节；[S] 保留作者经历与犹豫。

## 5. 标题 [K][借]

- 含具体对象（工具名、数字、事件），避免「AI 的未来」这类大词。
- 体现「我做了一件事 + 结果有点意外」。例：卡兹克的《淘宝上卖9块9的DeepSeek，让我看到了被折叠的魔幻世界》《亲手给AI投毒之后，我觉得……》。结构是动作 + 一个意料之外的观察。
- 能被验证。标题里的数字、结论，正文必须兑现。
- 不夸大。不写「炸裂」「颠覆」「史诗级」。
- 长度以一行读完、一眼知道在讲什么为准。
- 过 HKR：标题至少要有 H（让人好奇）。
- 写完正文后再回头改标题；备选至少三个，选最能被正文兑现的。

来源：[K] 爆款标题案例与 HKR；[H] 宣传腔。

## 6. 结尾：只放轻量的行动邀请 [借][K]

- 停在最后一个具体事实、一个还没解决的问题，或一个「接下来我打算做什么」。
- 可用的收法（卡兹克总结的）：回扣开头 / 引一句别人的话 / 一个短句留白 / 一个小行动。借风首选回扣开头和小行动。
- 轻量 CTA 最多一句：邀请读者对照自己的情况试一下，或告诉你他们的结果。不堆「点赞转发在看」，不连问三个问题。
- 不总结全文，不抒发愿景，不写「未来已来」。

来源：[K] 收尾几种方式、回环呼应；[H] 空泛升华、总结复述、聊天机器人式收尾。

## 7. 四层自检（交稿前）

由卡兹克的四层质检简化而来，适配借风。

L1 硬规则（机械扫描）
- 对照《ai-tone-checklist.md》，零命中「不是……而是……」「总而言之」「赋能/抓手/闭环」「首先其次最后」「随着……的发展」。
- 全文无空泛工具名。
- 标点约定检查。

L2 结构与节奏
- 开头三行是否落在具体事情上？
- 长短句是否交替？有没有一整段读起来像报告？
- 离题后有没有拉回主线？

L3 内容与证据
- 每个关键结论是否有对应证据（截图、原文、数字、时间）？
- 有没有失败和翻车？
- 每节读者能拿走一个动作或一个判断吗？
- 对比部分是否逐一展示，而非罗列？

L4 活人感通读
- 通读一遍：像一个真人在讲他做过的事，还是一份产品说明？
- 有没有哪一段需要回头重读才能顺下来？那里是节奏问题。
- 换一个人也能写出这篇吗？如果能，说明缺作者独有的细节。

卡兹克的原版有大量数量指标（至少 3 次断句、8 到 10 个口语词、至少一处自嘲）。借风不采用：配额会逼出编造。只保留方向。

来源：[K] 四层质检；[H][S] 改结构不换词、保真。

## 8. 与卡兹克的取舍

| 卡兹克做法 | 借风处理 |
|---|---|
| 长文不加小标题 | 叙述不加，教程操作段加 |
| 每篇文化升维 | 可选，接不上就不写 |
| 重口癖、网络梗 | 不搬运。那是他的声音，不是我们的 |
| 口语词、自嘲配额 | 不设配额 |
| 人物画像法（从数据想象具体的人） | 慎用。想象出来的人物很容易变成编造 |
| 4000 到 8000 字 | 看内容。够清楚就行，不凑 |
